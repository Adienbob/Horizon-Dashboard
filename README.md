# Horizon Dashboard

A fully responsive admin dashboard built from a Figma design, featuring data visualization, tables, kanban board, NFT marketplace, and user profile pages.

🔗 **[Live Demo](https://horizon-dashboard-clone.netlify.app/)**

---

## Preview

![Horizon Dashboard Preview](./public/assets/preview.png)

---

## Features

- **Main Dashboard** — earnings overview, revenue charts, task list, and team members
- **NFT Marketplace** — marketplace listings with card-based layout
- **Data Tables** — check table and complex table with status indicators and progress bars
- **Kanban Board** — task management board
- **Profile Page** — user profile with stats
- **Authentication** — sign in page

---

## Tech Stack

- **Next.js** — routing and SSR
- **TypeScript** — type safety throughout
- **Tailwind CSS** — utility-first styling
- **React** — component-based UI

---

## Getting Started

```bash
git clone https://github.com/Adienbob/Horizon-Dashboard.git
cd Horizon-Dashboard
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
